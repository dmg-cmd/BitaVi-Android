## LEYENDA VISUAL

```
[ Texto ]  = Boton / IconButton   |   ( Texto ) = Indicador / Label
{ Texto }  = Dialog / BottomSheet  |   < Texto > = FAB flotante
_ _ _ _ _  = Limite de pantalla    |   # # # # # = Barra de navegacion
```

## Referencia rapida de colores semanticos

| Constante | Color | Uso |
|-----------|-------|-----|
| `IconCompartir` | `0xFF4DD0E1` (Cian) | Botones de compartir/enviar |
| `IconExportar` | `0xFFFFB74D` (Amber) | Botones de exportar/guardar/descargar |
